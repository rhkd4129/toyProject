GitHub Actions 실행
  │
  ├─ 1. docker build ./frontend   ← Dockerfile 실행 (이미지 생성)
  │       └─ node로 빌드
  │       └─ nginx에 dist 복사
  │
  ├─ 2. docker push → Docker Hub  (이미지 업로드)
  │
  └─ 3. SSH로 EC2 접속
          └─ docker-compose pull  ← Hub에서 이미지 다운로드
          └─ docker-compose up -d ← 컨테이너 실행 (docker-compose.yml 읽음)



Actions: Docker Hub 로그인
    ↓
Actions: docker build ./frontend 명령 실행
    ↓
    Dockerfile 실행 (Actions 내부에서)
        └─ node로 npm install
        └─ npm run build → dist 생성
        └─ nginx 이미지에 dist 복사
    ↓
Actions로 돌아와서: docker push → Docker Hub
    ↓
Actions: SSH로 EC2 접속
    ↓
EC2: docker-compose pull (Hub에서 이미지 받아옴)
    ↓
EC2: docker-compose up -d (컨테이너 실행)



1. 개발자가 backend/** 코드 수정 후 main 브랜치에 push
        ↓
2. GitHub Actions 트리거

        [CI]
3. ./backend/Dockerfile로 이미지 빌드
        ↓
4. Docker Hub (rhkd4129/backend:latest)에 push
        ↓
        [CD]
5. EC2에 SSH 접속
        ↓
6. EC2에서 docker-compose pull
   → Docker Hub에서 새 이미지 다운
        ↓
7. docker-compose up -d
   → compose 설정(포트, 환경변수, DB연결) 적용해서 컨테이너 실행
