# PDF 채무자별 분리 스크립트 기능 정리

---

## 개요

여러 채무자가 합쳐진 PDF를 OCR로 분석해 **사람/문서 유형별로 자동 분리 저장**하는 자동화 도구.

- 실행 환경: Python (PyInstaller로 .exe 빌드 가능)
- OCR 엔진: EasyOCR (한국어 + 영어)
- PDF 처리: PyMuPDF (fitz)

---

## 처리 흐름

```
PDF 감지
  → 1패스: 쪽번호 스캔 (하단 1/8 OCR)
  → 2패스: 이름/키워드 스캔 (상단 1/2 OCR)
  → 세트 병합 처리
  → 개별 PDF 저장
```

---

## 1패스 — 쪽번호 스캔

- 각 페이지 **하단 1/8만** OCR → 속도 최적화
- `현재쪽/전체쪽` 패턴(예: `1/5`) 감지

| 감지 결과 | 처리 |
|---|---|
| `current == 1` | 새 채무자 시작, total 페이지 묶음으로 등록 후 건너뜀 |
| `current == None` | 쪽번호 없음 → `unknown_pages` 리스트에 모아둠 |
| `current != 1` | 직전 채무자 항목에 강제 편입 |

### 쪽번호 없는 페이지 처리

- 모두 모아서 **미상.pdf 하나**로 저장
- 각각 독립 파일로 만들지 않음

---

## 2패스 — 이름/키워드 스캔

- 각 채무자 첫 페이지 **상단 1/2만** OCR → 속도 최적화
- **키워드에 따라 이름 추출 방식이 다름**

| 키워드 | 이름 추출 방식 | 찾는 단어 |
|---|---|---|
| 지급명령 | `_extract_name` | `채무자` 다음 블록 |
| 이행권고결정, 판결 | `_extract_defendants` | `피고` 다음 블록(들) |
| 집행문, 송달/확정증명서 | 추출 안 함 | — |
| 키워드 없음 | `_extract_name` | `채무자` 다음 블록 |

---

## 이름 추출 상세

### 채무자 추출 (`_extract_name`)

- OCR 블록 순회 중 `채무자` 감지 → 바로 다음 블록을 이름으로 반환
- 블록마다 공백 제거 후 비교 (`채 무 자` → `채무자` 매칭)

### 피고 추출 (`_extract_defendants`)

- `피고` 감지 후 이름 수집
- **단일 피고**: 바로 다음 블록이 이름
- **복수 피고**: `1.이름`, `2.이름` 번호 패턴으로 수집 → `list[str]` 반환
- 날짜(`2022.`)와 구분하기 위해 **1~2자리 숫자**만 번호로 인식

### 이름 정제 (`_clean_name`)

- 숫자 또는 `(` 가 나오기 전까지 자름
  - 예: `주식회사서현에프앤디(28...` → `주식회사서현에프앤디`
- 최대 **10글자** 제한
- 법인명, 개인 모두 동일하게 처리 (타입 구분 없음)

### OCR 공백 문제 대응

- `지 급명 령` 같이 OCR이 띄어쓰기를 끊는 경우를 대비
- 키워드 비교 시 전체 텍스트에서 **공백 제거 후 비교**

---

## 5개 키워드

```
지급명령 / 이행권고결정 / 판결 / 집행문 / 송달/확정증명서
```

---

## 세트 병합 — 판결 + 집행문 + 송달/확정증명서

이 3개는 별도 그룹으로 잡히지만 실제로는 하나의 세트.

### 규칙

- 연속된 3개 그룹의 키워드가 `{판결, 집행문, 송달/확정증명서}` 조합이면 **자동 병합**
- 순서는 어떤 순서든 상관없음 (보장 안 됨)
- 3개 연속 등장 보장, 3개 모두 등장 보장
- **이름은 판결 그룹에서만 추출** (집행문/송달확정증명서에는 채무자 없음)
- 3개 페이지 합쳐서 PDF 하나로 저장

---

## 파일명 규칙

| 상황 | 파일명 |
|---|---|
| 이름 O + 키워드 O | `{이름}{키워드}.pdf` |
| 이름 O + 키워드 없음 | `{이름}_키워드불명.pdf` |
| 이름 없음 (판결 세트 등) | `미상판결.pdf` |
| 쪽번호 없는 페이지 전체 | `미상.pdf` |
| 복수 피고 | `{피고1이름}{피고2이름}{키워드}.pdf` |
| 중복 파일명 | `{파일명}_2.pdf`, `{파일명}_3.pdf` ... |

### 이름 길이

- 단일 이름: 앞 3글자 (채무자) 또는 `_clean_name` 결과 (피고)
- 법인명 포함 모두 동일하게 처리

---

## 저장 위치

```
실행파일 위치/
  └── YYYYMMDD_HH/       ← 실행 시각 기준 폴더 자동 생성
        ├── 홍길동지급명령.pdf
        ├── 노해영노수웅판결.pdf
        ├── 박광용이행권고결정.pdf
        ├── 홍길동_키워드불명.pdf
        └── 미상.pdf
```

---

## 예외 처리

| 상황 | 처리 |
|---|---|
| PDF 없음 | 오류 출력 후 종료 |
| PDF 여러 개 | 오류 출력 후 종료 |
| 판결 그룹에서 이름 못 찾음 | 세트 전체 `미상판결.pdf` |
| 키워드 못 찾음 | `{이름}_키워드불명.pdf` |
| 이름 + 키워드 둘 다 없음 | `미상.pdf` 묶음에 합류 |
